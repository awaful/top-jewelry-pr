## 💎 1. Descripción del Proyecto

**TOP JEWELRY PR** es una experiencia web cinematográfica y editorial de joyería contemporánea, diseñada con dirección de arte premium, animaciones fluidas y una arquitectura web moderna.

Características principales:
- Experiencia inmersiva con dirección visual en negro obsidiana, acentos dorados y tipografía monumental.
- Narrativa editorial y fotografía de campaña en alta resolución.
- Animaciones cinematográficas coordinadas mediante GSAP, ScrollTrigger y scroll suave con Lenis.
- Diseño totalmente adaptable para dispositivos móviles y de escritorio.
- Accesibilidad integrada con soporte para `prefers-reduced-motion`.

---

## 🎨 2. Identidad Visual & Dirección Artística

- **Paleta de Color**:
  - Negro Obsidiana (`#050403`): Fondo cinematográfico primario.
  - Champán y Dorado (`#D6BD91`, `#B58A4B`): Detalles, acentos sutiles y micro-interacciones.
  - Blanco Cálido (`#FFF9F2`): Tipografía monumental de alto contraste.
- **Tipografía**:
  - Titulares monumentales de estilo arquitectónico y editorial.
  - Tipografía técnica y monoespaciada para microtextos de calibración y navegación.

---

## 🏗️ 3. Tecnologías y Librerías

- **Frontend**: HTML5, Tailwind CSS, JavaScript modular.
- **Animación & Render**: GSAP 3 (ScrollTrigger, Flip), Three.js (escena de partículas y atmósfera), Lenis (scroll suave).
- **Servidor de Desarrollo**: Node.js HTTP server autónomo (`preview-server.js`).

---

## 🚀 4. Puesta en Marcha

### Requisitos
- Node.js (versión 18 o superior).

### Ejecución Local
```bash
# Iniciar el servidor de previsualización
node preview-server.js
```
Abre tu navegador en `http://localhost:3000`.
